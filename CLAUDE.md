# Azure Workflow and Engineering Guidance

Read and follow the project-specific Azure sandbox instructions
in @claude-code-azure-workflow-handout.md.

Important:
- Deploy only inside the five assigned resource groups.
- Respect the $500 Azure spending limit.
- Use only the permitted Azure regions and services.
- Never expose API keys, credentials, or secrets.
- Ask for explicit approval before costly or destructive Azure operations.
- Keep infrastructure changes reproducible and documented.
